## <a name="v0.33.0">v0.33.0</a> - 2026-10-25

This release adds support for GitHub's native PR stacks.
git-spice's `submit` commands will automatically create or recreate GitHub stacks, and `merge` commands will merge them with stack-merge operations when possible.

### Added
- submit: Eligible GitHub pull requests are registered as native stacks after submission.
- merge: Eligible GitHub pull request stacks are merged atomically.
- forge: Extra HTTP headers can be configured with `spice.http.$host.header` and `spice.http.$host.headerFromEnv`.
- Add a `spice.color` configuration option to control colored output. Git's `color.ui` option is also supported.
- submit: Allow limiting downstack history in navigation comments by setting the `spice.submit.navigationComment.downstack` option to a positive integer.
### Fixed
- log: Short and long branch listings are faster in repositories with many tracked branches. We observed `git-spice log short` improve by 3x (1.5s => 0.5s) in a repository with 100 branches.
- ui: Fix terminal keyboard state left in a broken state after a prompt.
- ui: Branch selection is updated to the best match as the filter changes, retaining focus among matches tied for the highest fuzzy score.
- restack: Fix branches in Git submodules being skipped.
- merge: Externally merged changes are detected while waiting for readiness, and the remaining stack is merged normally.
- merge: A race that could abandon branches after preparation is fixed.
