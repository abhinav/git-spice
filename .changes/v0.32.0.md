## <a name="v0.32.0">v0.32.0</a> - 2026-10-12
### Added
- Add support for Azure DevOps (Azure Repos) as a forge.
- Add commands for drafting, publishing, and managing review comments
- navigation: Add `spice.submit.navigationComment.trunkComparison` configuration option to include a link comparing the branch against trunk in navigation comments, on the topmost or all CRs of a stack.
- repo sync: Other worktrees may be detached before deleting their merged branches by enabling `spice.repoSync.detachWorktrees`.
- submit: Add `spice.submit.navigationCommentStyle.layout` option. Set it to `simple` to show navigation comments as a flat list from the top of the stack down to the trunk branch. Comments on changes with a fork above them keep the tree layout.
### Changed
- repo sync: Discover PRs submitted to GitHub outside git-spice in batches, reducing number of API calls.
- Bitbucket Cloud: stack navigation comments now reference pull requests as inline cards, so each entry shows the pull request's title and state instead of just its number.
### Fixed
- log: Automatically heal from branches changed manually to point to a commit in their base branch.
- GitLab: Fix CLI token extraction in newer versions of glab.
- Sibling branches in rendered branch trees are no longer unaligned when one of them has upstack branches and the other does not.
- stack submit: Pull requests are now created with the correct base branches when existing remote branches have the same names as the local stack.
- Bitbucket Cloud: `branch submit` now reuses an existing pull request for an unchanged branch instead of creating a duplicate pull request on a suffixed branch or pushing the branch again.
